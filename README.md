> 面向「有 TypeScript / JavaScript 基础、但完全没写过 AI Agent」的程序员。

## 这是什么

市面上大多数 AI Agent 教程，上来就让你 `npm i langchain`，然后贴一堆 API 调用，你学会了"怎么用"，却不知道"为什么"。

这本教程反过来：**我们一行一行从零手写一个 Agent**——消息管理、工具调用、记忆、循环控制、结构化输出、安全护栏——等你把每一个零件亲手造出来，再看 LangGraph 这类框架，你会发现它们不过是把你造过的轮子"标准化"了而已。

**读完你会得到：**
- 一个真正能跑的、分层的 Agent 应用（含完整代码，退出码 0 可验证）
- 对 Agent 每一个设计决策的"为什么"
- 一套面试能打的底子（50+ 高频题 + 白板题）

## 环境搭建

你只需要一样东西：**Node.js 22 LTS**（本教程实测版本 22.22.2）。

```bash
node -v   # 期望输出 v22.x.x
```

**零第三方依赖**：核心章节（00~09）只用 Node 内置模块，`node xxx.mjs` 直接跑，无需 `npm install`。

**关于 LLM API**：本教程的示例采用「可插拔 mock」策略——所有 LLM 调用点都抽成一个 `llm` 接口，默认走内置 mock，**离线也能跑通、退出码 0**。当你准备接真实模型时，只需把 mock 换成一次 `fetch` 调用（第 03、09 章会详细讲怎么接 OpenAI / 国产模型）。

## 三条铁律

1. **先跑通，再理解**——每个示例都能直接 `node` 运行，先看结果，再看代码。
2. **每一个"为什么"都要追到底**——不满足于"能跑"，要问"为什么这么设计""代价是什么"。
3. **报错要亲手复现**——教程里所有报错都带错误码、标了触发条件，请你亲手跑一遍，别只看。
